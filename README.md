# Sri Saraswathi Maths Tuition Centre - Web Portal

A bespoke, high-performance landing page tailored for Sri Saraswathi Maths Tuition Centre (Tuticorin). This portal transitions traditional educational flier data into a premium, future-forward digital experience designed to maximize student conversions and batch management clarity.

## ✨ Key Features
- **Cyber-Glassmorphism UI:** A sleek, high-contrast visual theme tailored to engage modern students and parents alike.
- **Dynamic Batch Matrix:** Optimized grid displaying curriculum tracks, schedules, and daily batch splits uniformly.
- **Performance Optimized:** Built with clean, semantic vanilla HTML5, CSS3 variables, and vanilla JavaScript for instantaneous load speeds.
- **Fully Responsive Architecture:** Pixel-perfect adaptation across mobile, tablet, and desktop viewports.

## 🛠️ Technology Stack
- **Frontend:** HTML5, CSS3 (Custom Properties & Grid/Flexbox Architectures)
- **Icons:** FontAwesome v6.0.0
- **Typography:** Google Fonts (Orbitron & Rajdhani)
